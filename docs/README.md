# Dokumentasi Tovv

Semua nama file dokumen memakai huruf kapital dengan garis bawah, sama seperti paket spesifikasi. Isi dokumen berbahasa Indonesia.

| Dokumen | Isi |
|---|---|
| [`spec/`](spec/) | Paket spesifikasi 2.1 — sumber kebenaran scope dan aturan bisnis: [PRD](spec/PRD.md), [ARCHITECTURE](spec/ARCHITECTURE.md), [INTEGRATION_PLAN](spec/INTEGRATION_PLAN.md), [IMPLEMENTATION_PLAN](spec/IMPLEMENTATION_PLAN.md) (termasuk status task terbaru di §0), [TEST_PLAN](spec/TEST_PLAN.md), [VALIDATION_PLAN](spec/VALIDATION_PLAN.md) |
| [`PRODUCT.md`](PRODUCT.md) | Ringkasan produk untuk keputusan desain: pengguna, batasan, komitmen merek |
| [`DESIGN.md`](DESIGN.md) | Sistem desain yang terkirim: token terang/gelap, tipografi, komponen, gerak |
| [`SCREEN_INVENTORY.md`](SCREEN_INVENTORY.md) | Daftar layar per peran vs requirement: tersedia / disimulasikan / belum |
| [`DEVELOPMENT.md`](DEVELOPMENT.md) | Versi, cara menjalankan di HP/emulator, mode demo, dua bahasa, peta, struktur kode |
| [`QA_REPORT.md`](QA_REPORT.md) | Hasil pemeriksaan per putaran (otomatis, perangkat, review desain, blocker) |

Dokumen di luar `spec/` hanya melengkapi tahap implementasi dan tidak menyalin PRD. Status kerja dan serah terima antar-sesi ada di [`../.ai/project-status.md`](../.ai/project-status.md).

Nama produk tampil adalah **Tovv** (riwayat nama di PRD §10). Solveit Indonesia tampil sebagai pemilik/pengembang di halaman Tentang.
